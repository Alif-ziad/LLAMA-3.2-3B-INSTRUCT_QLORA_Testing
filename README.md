# Llama-3.2-3B-Instruct — QLoRA Testing

Evaluation-artifact repository for code-repair generation using **Llama-3.2-3B-Instruct**.

## Published outputs

- Progressive `generated_fixes_partial_*samples.csv` files
- `generated_fixes_full.csv`
- `per_bug_type_metrics_full.csv`
- Repository history recording generation completion at **2,510 / 2,510**

## Reporting guidance

Use `generated_fixes_full.csv` as the completed generation output for this run. The partial CSVs are progress/resume snapshots, not separate final evaluations. Per-bug-type metrics should be interpreted under the same generation/evaluation protocol used for the full output.

## Scope

This repository preserves evaluation results and analysis artifacts; it is not a packaged inference application.
